## Контекст

Для MVP выбран встроенный полнотекстовый поиск PostgreSQL — Elasticsearch
посчитали избыточным на текущем этапе. В основе связка `tsvector` + GIN-индекс
с поддержкой русской морфологии через словарь `ru_stem`.
