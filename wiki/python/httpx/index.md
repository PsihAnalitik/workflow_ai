# wiki: python/httpx (v1)

httpx — современный HTTP-клиент для Python (синхронный/асинхронный,
HTTP/1.1, HTTP/2). Базовые возможности: таймауты, аутентификация,
пулы соединений, автоматическое следование редиректам.
