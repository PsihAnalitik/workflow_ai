# wiki: agents/prompts (v1)

Прожарка LLM-промптов: методология ревью и авторинга по prompt_guide
(belief state / семантическая интерференция / curse of instructions).

- [review.md](review.md) — методология: механизмы (включая хвостовую инструкцию <task>), процедура П1–П10,
  severity и формат находок под гейт M-07, КАНОНИЧЕСКИЙ ШАБЛОН промпта (обязателен
  для новых промптов, проверяется измерением П10).
- [grounding_tags.md](grounding_tags.md) — инженерная проверка фабрикации:
  протокол found_data (inline-разметка данных + детерминированные гейты),
  правило четырёх точек синхронизации.
- [examples/](examples/index.md) — хорошие и плохие примеры, лучшие практики.
