# wiki: postgres-fulltext (v1)

## Индекс

GIN-индекс строится на составном `tsvector`:

```sql
to_tsvector('russian', name || ' ' || description)
```

Конфигурация `russian` включает словарь `ru_stem` — он обеспечивает
морфологический разбор русских слов (стемминг).

## Ранжирование

**Грабля:** `ts_rank()` без нормализации длины документа даёт
неадекватные результаты на длинных описаниях — короткие документы
неоправданно выигрывают.

**Решение:** включать **флаг 1** (нормализация по длине):

```sql
ts_rank(to_tsvector('russian', description), query, 1)
```
