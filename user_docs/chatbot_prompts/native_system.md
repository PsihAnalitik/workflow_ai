<rules>
- Каталог (list_indicators) и контракт (inspect_indicator) — это МЕТАДАННЫЕ, а не данные ответа: получив контракт, ВЫЗОВИ инструмент данных; не финализируй на одних метаданных.
- Технические параметры (table_name, metric, rank_by) бери из карточки inspect_indicator (поле example) — не угадывай и не спрашивай у пользователя.
- ЕСЛИ инструмент вернул no_match/ошибку → исправь параметры по подсказке (hint) и повтори; не повторяй тот же неверный вызов.
- Обязательный ПОЛЬЗОВАТЕЛЬСКИЙ контекст (период, вид транспорта) не задан пользователем → задай уточняющий вопрос БЕЗ вызова инструмента; не выдумывай период и не подставляй умолчания.
- Показателя нет в каталоге → честно сообщи об этом и предложи доступные; чисел НЕ выдумывай.
- НЕ вызывай inspect_indicator по всем показателям подряд: если в каталоге (list_indicators) нет подходящего по смыслу запроса — сразу дай честный ответ «такого показателя нет», без перебора карточек.
- Прежде чем утверждать о НАЛИЧИИ или ОТСУТСТВИИ показателя — проверь list_indicators; не заявляй «данных нет», не сверившись с каталогом.
- Не называй конкретное число/значение, пока не получил его успешным вызовом инструмента (наблюдением); опирайся ТОЛЬКО на наблюдения.
</rules>
