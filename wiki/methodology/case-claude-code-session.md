# wiki: хроника сессии Claude Code 10–11.07.2026 (v1)

Живой кейс совместной работы человека и LLM-агента над agent_workshop —
итерации v6→v9 за два дня. Показывает, как методология прожарки промптов,
батч-механика и HITL-приёмка работают в реальной разработке.

## День 1 (10.07)

- **Проверка инструментов.** MCP-сервер agent-workshop и web_search (Tavily)
  живы. Узел wiki_spec цеха wiki_maintainer дважды вызвал web_search
  (подтвердил версию httpx 0.28.1 и имя пакета), карточка httpx применена
  wiki-apply.
- **M-22 workshop/material.py — «вики из чатов».** Материал чанкуется по
  заголовкам (id вида d1:03); вход больше лимита идёт узлам оглавлением,
  содержимое читается инструментами material_search/material_get. Протокол
  Retriever — seam под векторный RAG (MVP лексический). Smoke: из выгрузки
  чата о платежах и поиске построены области payments/ и search/ с точными
  фактами (идемпотентность по event.id, активация по invoice.paid).
- **Разведка ailab.** Три параллельных разведчика: карта сервисов,
  RAG-пайплайн, агентные паттерны. Заимствовано в v7: retry-стратегия
  поиска в описании инструмента (переформулируй → обобщи → после 3 неудач
  вернись к оглавлению); chunk_overlap (400 на чанк 4000); инструменты
  wiki_search/wiki_get — адресная маршрутизация вместо тотального бандла;
  RemoteBGEM3Retriever под контракт POST /encode (образ сервиса на машине
  не найден — только клиент). Урок: даже большой продукт живёт на dense
  top-k без reranking, написанные «на вырост» сплиттеры мертвы —
  Simplicity First подтверждён.

## Уроки сессии

1. **Правило ревью без негативного случая зацикливает генератор.**
   Кейсы: R3 «неадресная локация» при структурном дефекте всего файла;
   V3-педантизм к строкам «находок нет». Лечится негативным случаем
   в правиле и жёстким шаблоном формата отчёта.
2. **Промпт-пример в спецификаторе должен покрывать краевой случай**
   (новая область + leaf-страница), иначе цикл спека-ревью не сходится.
3. **Батч-механику (map) правильно держать в детерминированном драйвере,**
   а не в FSM оркестратора.
