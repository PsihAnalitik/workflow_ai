# wiki: table-validation (v1)

Цех `table_roaster` — валидация таблиц схемы БД по измерениям T1–T7.
Работает как map-прогон: каждая таблица — независимый элемент со своим
стором, журналом и вердиктом PASS/FAIL.

## Измерения T1–T7

| Изм. | Что проверяется |
|---|---|
| T1 | Описание таблицы ↔ реальные колонки: колонки есть в схеме, но не упомянуты в description |
| T2 | Типы колонок: несоответствие заявленного типа и реального |
| T3 | Агрегации: AVG на метриках-средних — гарантированно неверный SQL |
| T4 | Значения: description колонки противоречит example-значениям |
| T5 | Карточки таблиц (table_cards): granularity расходится с таблицей, устаревшие метрики |
| T6 | Инструменты: битые ссылки тулов на несуществующие колонки |
| T7 | Сверка с БД: db_query берёт реальные значения из БД, сравнивает с описанием |

## Трёхсторонний join

Сердце валидации — сверка трёх артефактов:
`schema.yaml` ↔ `tools.yaml` ↔ `table_cards`.
Модель строит эталон из полного перечня ключей всех трёх источников
и ищет расхождения:
- колонка есть в schema, но отсутствует в описании тула → T6
- карточка ссылается на метрику, которой нет в таблице → T5
- `nullable: true` в схеме, а в карточке «REQUIRED» → T1

**Урок шаблона:** эталон снимается с полного перечня ключей, не с топ-N —
иначе честные колонки попадают в «неизвестный ключ» и зашумляют T1.

## db_query

Инструмент read-only: одиночный SELECT (DML/DDL и мультистейтменты отсекаются
до обращения к БД), LIMIT дописывается принудительно. DSN — только из
`WORKSHOP_DB_DSN`; без DSN узел жив, модель получает текстовую ошибку и
помечает «T7: БД недоступна». MVP-драйвер psycopg; Vertica подключается
новой реализацией `DbClient` без изменения инструмента.

## Результаты прогона (53 таблицы smart-assistant)

**51 FAIL / 2 PASS; 39 находок p3, 115 p2:**
- T5 (карточки): 63 находки — granularity расходится, устаревшие метрики
- T1 (описание↔колонки): 32 находки — ключевые колонки не в description
- T3 (агрегации): 20 находок — AVG на `avg_trip_distance` и подобных
- T6 (битые ссылки тулов): остальное

Приятная находка: `trip_cnt_per_1_vehicle: aggregation: avg` продублирован
и в `tools.yaml` — системная ошибка в обоих артефактах.
